# دار السلع — تطبيق الجوال (Expo + Supabase)

نسخة مطابقة لتطبيق `souq-mobile`: نفس الشاشات والتصميم والتنقل. الفرق أنها تعمل مباشرة على Supabase بدل خادم Manus وقاعدة MySQL.

## التشغيل

```bash
pnpm install
pnpm start          # ثم امسح رمز QR بتطبيق Expo Go على أندرويد
pnpm web            # معاينة في المتصفح
```

## الإعدادات

ملف `.env` يحتوي على مفتاح Supabase العام (publishable) لمشروع **الاختبار**:

```
EXPO_PUBLIC_SUPABASE_URL=...
EXPO_PUBLIC_SUPABASE_KEY=sb_publishable_...
```

لا تضع مفتاح `service_role` في التطبيق أبدًا.

### تسجيل الدخول

- **البريد الإلكتروني وكلمة المرور:** يعمل مباشرة.
- **Facebook:** فعّله من Supabase ← Authentication ← Providers، ثم أضف هذين الرابطين إلى Redirect URLs:
  - `daralsila://oauth/callback`
  - رابط موقع الويب إن وُجد، مثل `https://<domain>/oauth/callback`
- **Google:** بقي «قيد الإعداد» كما في الأصل. الدالة `startGoogleLogin` جاهزة في `constants/oauth.ts` عندما تقرر تفعيله.

## اللغتان

- كل نصوص الواجهة تمر عبر `t("النص العربي")` من `lib/i18n`، والترجمة الإنجليزية في `lib/i18n/en.ts`.
- يتبدل اتجاه الواجهة فورًا (عربي RTL ↔ إنجليزي LTR) من «حسابي» أو «الإعدادات»، ويُحفظ الاختيار على الجهاز.
- أنماط الشاشات تُكتب بـ `createStyles` من `lib/i18n/rtl.ts` (بدل `StyleSheet.create`) لتنعكس تلقائيًا في الإنجليزية.
- أسماء التصنيفات والمواقع تأتي من قاعدة البيانات بالحقلين `name_ar` و `name`.
- `pnpm test` يتحقق أن لكل نص عربي ترجمة إنجليزية وأن المتغيرات `{n}` متطابقة.

## قاعدة البيانات (مشروع الاختبار)

ملفات التعديل في `supabase/migrations/` مطبّقة على مشروع **الاختبار** فقط:

| الملف | المحتوى |
|---|---|
| `0001_mobile_features.sql` | الأدوار، الاشتراكات، المشاهدات، التقييم، المتابعة، الإشعارات، البلاغات |
| `0002_marketplace_spec.sql` | حالات الإعلان (قيد المراجعة/موقوف/مرفوض)، جدول المتاجر، الحظر، صور الرسائل، أسباب البلاغ، إشعارات قرارات المراجعة، سجل إجراءات المشرف، إعدادات المنصة |
| `0003_harden_function_grants.sql` | تقييد صلاحيات تنفيذ الدوال |
| `0004_category_english_names.sql` | الأسماء الإنجليزية لـ 176 تصنيفًا |

- الصلاحيات تُفرض في قاعدة البيانات (RLS ومشغّلات)، لا بإخفاء الأزرار: المستخدم لا يرقّي نفسه، ولا يوافق على إعلانه، ولا يقرأ محادثات غيره.
- **تعيين أول مشرف:** من محرر SQL في Supabase:
  `update profiles set role = 'admin' where id = '<uuid>';`
- طريقة النشر (فوري أو بعد موافقة المشرف) من لوحة المشرف ← إعدادات المنصة.

## الفروق عن الأصل

| الأصل (Manus) | هذه النسخة |
|---|---|
| خادم tRPC + MySQL | استدعاءات Supabase مباشرة في `lib/data.ts` |
| شاشات أقسام بقوائم ثابتة | شجرة تصنيفات من قاعدة البيانات وشاشة قسم واحدة `/category/[slug]` |
| فحص الإعلانات والصور بالذكاء الاصطناعي | فحص بقائمة كلمات ممنوعة ونوع الصورة؛ الفحص بالذكاء الاصطناعي ينتظر قرارًا |
| حذف الحساب كاملًا | يحذف الإعلانات والصور والمفضلة ويخرج المستخدم. حذف حساب المصادقة نفسه يحتاج Edge Function بصلاحية خادم |

انظر `docs/SPEC-GAP.md` لمقارنة كل قسم في الوثيقة بما نُفّذ.
