# دار السلع — تطبيق الجوال (Expo + Supabase)

نسخة مطابقة لتطبيق `souq-mobile`: نفس الشاشات والتصميم والتنقل. الفرق أنها تعمل مباشرة على Supabase بدل خادم Manus وقاعدة MySQL.

## التشغيل

```bash
pnpm install
pnpm start          # ثم امسح رمز QR بتطبيق Expo Go على أندرويد
pnpm web            # معاينة في المتصفح
```

## الإعدادات

ملف `.env` يحتوي على مفتاح Supabase العام (publishable) لمشروع **الاختبار**:

```
EXPO_PUBLIC_SUPABASE_URL=...
EXPO_PUBLIC_SUPABASE_KEY=sb_publishable_...
```

لا تضع مفتاح `service_role` في التطبيق أبدًا.

### تسجيل الدخول

- **البريد الإلكتروني وكلمة المرور:** يعمل مباشرة.
- **Facebook:** فعّله من Supabase ← Authentication ← Providers، ثم أضف هذين الرابطين إلى Redirect URLs:
  - `daralsila://oauth/callback`
  - رابط موقع الويب إن وُجد، مثل `https://<domain>/oauth/callback`
- **Google:** بقي «قيد الإعداد» كما في الأصل. الدالة `startGoogleLogin` جاهزة في `constants/oauth.ts` عندما تقرر تفعيله.

## قاعدة البيانات

| يعمل الآن على الجداول الموجودة | يحتاج ملف التعديل `supabase/migrations/0001_mobile_features.sql` |
|---|---|
| الإعلانات، الصور، التصنيفات، المواقع، المفضلة، نشر الإعلانات والمسودات، إعلاناتي | المتاجر والاشتراكات، المحادثات، الإشعارات، البلاغات، التقييم، المتابعة، سجل المشاهدات، لوحة المشرف |

- **قبل تطبيق الملف:** تظهر الشاشات التي تعتمد على هذه الجداول فارغة أو تعرض رسالة «هذه الميزة تحتاج تفعيل جداولها». لا يتعطل التطبيق.
- **طبيعة الملف:** إضافات فقط، ولا يحذف أو يغيّر أي جدول موجود.
- **الاختبار:** جُرّب الملف على قاعدة Postgres محلية مع 12 اختبار صلاحيات، ونجحت كلها. منها أن المستخدم لا يستطيع ترقية نفسه إلى مشرف، ولا قراءة محادثات غيره، ولا تقييم إعلانه.
- **تعيين أول مشرف بعد التطبيق:** من محرر SQL في Supabase:
  `update profiles set role = 'admin' where id = '<uuid>';`

## الفروق عن الأصل

| الأصل (Manus) | هذه النسخة |
|---|---|
| خادم tRPC + MySQL | استدعاءات Supabase مباشرة في `lib/data.ts`، مع طبقة توافق في `lib/trpc.ts` حتى تبقى الشاشات كما هي |
| فحص الإعلانات والصور بالذكاء الاصطناعي | فحص محلي بقائمة كلمات ممنوعة ونوع الصورة. يمكن نقل الفحص بالذكاء الاصطناعي لاحقًا إلى Edge Function |
| الإعلان يمر بحالة «قيد المراجعة» | ينشر مباشرة، لأن جدول الإعلانات في Supabase لا يحوي هذه الحالة، ويستطيع المشرف إيقافه |
| زرّا تبويب زائدان «post» و«myads» في الشريط السفلي | مخفيان، لأنهما خطأ في الأصل |
| حلقة تسجيل مشاهدات متكررة في شاشة الإعلان | أُصلحت |
| حذف الحساب كاملًا | يحذف الإعلانات والصور والمفضلة ويخرج المستخدم. حذف حساب المصادقة نفسه يحتاج Edge Function بصلاحية خادم |
